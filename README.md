# Brief SQL

Exercice SQL sur les tables "wizard" et "school" réalisés sur Supabase

# Exercices :

1. Créer les tables "wizard" et "school" pour l'exercice 1.
2. Utiliser SELECT, INSERT, WHERE, DELETE sur "school" et avec "wizard" pour afficher les élèves et écoles ajoutées avec la base de données, les modifier, et les supprimer pour les exercices 2 et 3.
3. Schéma Excalidraw à faire avec "Potion – utiliser – Ingrédients"
4. Mise en place du Github pour envoyer les exercices.
